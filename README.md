# Infraestrutura como Código — Exercícios

Repositório de apoio a estudos introdutórios de infraestrutura como código e automação de ambientes.

Consulte os arquivos-fonte para identificar provedores, ferramentas e recursos efetivamente utilizados. Antes de aplicar configurações, revise permissões, custos potenciais e recursos que serão criados ou alterados.

Material educacional; não representa por si só uma infraestrutura de produção.
